# JSON風コメントの書き方

1. 要約 `.claude/cloud-rules/COMMENT_RULES.md` を読む（短い）。
2. 依頼対象: $ARGUMENTS（無ければ今回新規作成・変更した宣言）。
3. 対象宣言（クラス・関数・メソッド）の直前に、日本語キーのJSON風コメントを書く。
   - クラス: 責務・フィールド（必須）、処理（推奨）。
   - 関数・メソッド: 責務・処理・引数・戻り値（必須。戻り値なしは `[]`）。
   - 副作用・エラー・補足は、実際にある時だけ書く。
4. 内部の処理単位・変数の意味・理由は日本語の通常コメントで書く。処理の区切りは宣言前の「処理」と対応させる。
5. 有効なJSONか確認する（末尾カンマ・本文中コメント・重複キーなし）。可能なら本文だけ取り出して構文検査する。
6. 既存コードの一括書換えはしない。触った宣言だけ直す。生成物・vendor・外部コードは対象外。

完了条件: 変更した宣言のコメントが有効なJSONで、必須項目が埋まり、実装と一致している。完了報告に付与・更新した宣言を書く。
