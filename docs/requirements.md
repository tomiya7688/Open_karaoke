# 要件

## 目的

Open_karaoke は、ユーザーが原曲を用意するだけでカラオケに必要なデータを可能な限り自動生成し、そのまま歌唱・音程表示・採点まで行えることを目標とする。

人間による修正は可能にするが、通常利用では修正を前提としない。低信頼箇所もまず自動再解析し、機械側で可能な限り正解へ収束させる。

さらに、対応機材と必要な権利処理・許認可を整えれば、個人や事業者がこのアプリを用いて商用カラオケ環境を構築できることを製品要件とする。

## 商用利用要件

採用するライブラリ、モデル、ランタイム、学習済み重み、付属ツールは商用利用可能であることを最低条件とする。

OSSを優先するが、精度・保守性・実用性に不安が残る場合は、商用利用条件を満たす非OSSコンポーネントも選択肢に含める。

コード本体のライセンスだけでなく、学習済み重み、同梱バイナリ、依存ライブラリ、モデル配布条件も個別に確認する。

## 入力

### 原曲

以下を読み込めることを目標とする。

- WAV
- AAC
- MP3
- MP4

動画ファイルの場合は音声を抽出して解析する。

### 参考データ

以下は任意入力とする。

- 既存歌詞
- MIDI 等の既存譜面
- 将来的には既存のカラオケ譜面形式

参考データは絶対的な正解として扱わず、音声解析結果と照合するための強い証拠として扱う。

## 曲データ生成

原曲から以下を生成する。

- ボーカル音源
- 伴奏音源
- 歌詞
- 歌詞タイミング
- 採点用音程譜面
- 曲構造情報
- 各推定結果の信頼度
- 必要に応じて各モデルの根拠データ

生成した曲データはキャッシュし、歌唱のたびに重いAI解析をやり直さない。

## カラオケ再生

- ボーカルを除いた伴奏を再生できる
- 歌詞を同期表示できる
- 正解音程を音程バーとして表示できる
- ユーザーの歌唱音程をリアルタイム表示できる
- マイク入力をスピーカーへ返せる
- マイクへエコー / リバーブを適用できる
- 音楽音量を調整できる
- マイク音量を調整できる
- エコー量を調整できる
- 入力音程と期待音程を比較できる
- 採点できる

## 採点

採点は単一のブラックボックス値ではなく、複数の独立指標を算出して合成する。

初期の主要指標:

- Pitch accuracy
- Timing accuracy
- Note coverage / duration coverage
- Stability

将来的な追加候補:

- Long tone
- Vibrato
- Dynamics / 抑揚
- 表現系評価

採点時はオーディオデバイス由来のマイク遅延を補正できる設計にする。

採点式・閾値・重みは固定値として埋め込まず、Evaluatorによるベンチマーク結果から校正可能にする。

## バージョン方針

0.1.x 系は機能単位・検証単位で細かくリリースしてよい。

1.0.0 は、当初定義した主要なカラオケ機能を一通り実装し、リリース前評価を通過した最初の正式版とする。

1.0.0 までに少なくとも以下を含める。

- 原曲読み込み
- カラオケ伴奏生成
- 歌詞生成
- 歌詞同期
- 譜面生成
- 外部譜面インポート
- マイク入力
- マイクモニタリング
- Echo / Reverb
- 音楽 / マイク / エフェクト音量調整
- 音程バー
- リアルタイム音程判定
- 採点
- 曲データ保存・再利用
- モデル差し替え可能な解析基盤

## 品質評価とCI

1機能を実装するごとに、その機能を静的・自動的に評価できるEvaluatorを用意する。

EvaluatorはCIへ組み込み、回帰を検出する。

例:

- Stem separation quality evaluator
- ASR / lyric evaluator
- Alignment evaluator
- Pitch evaluator
- Note transcription evaluator
- Scoring evaluator
- API contract evaluator
- Audio latency / synchronization evaluator

通常CIでは軽量な固定データセットを使い、1.0.0正式リリース前にはより大きな評価セットで精度・品質を測定する。

## 編集

自動生成結果は編集可能とする。

ただし通常フローでは、ユーザーに大量の修正を要求しない。

目標フロー:

1. AIが生成
2. 複数モデルとルールで検証
3. 低信頼箇所を自動再解析
4. 最有力結果を自動確定
5. 必要なユーザーだけ任意で微修正

低信頼箇所が残っていても、原則としてカラオケ開始を妨げない。
